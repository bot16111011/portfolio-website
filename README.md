# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

## Contact form configuration

The contact form uses EmailJS. Copy `.env.example` to `.env.local` and fill in the three EmailJS values before running the app locally or deploying it. Configure the same `VITE_EMAILJS_SERVICE_ID`, `VITE_EMAILJS_TEMPLATE_ID`, and `VITE_EMAILJS_PUBLIC_KEY` variables in the deployment provider.
